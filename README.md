# 기억 박물관 전시관

초등학교 수업에서 실물화상기·웹캠·사진 파일로 작품을 모으는 범용 전시 웹앱입니다. HTML/CSS/JavaScript로 작성했으며 **빌드, 로그인, AI API, 데이터 서버 없이** 실행합니다. QR 라이브러리도 함께 포함하여 실행 중 CDN을 호출하지 않습니다.

## 이미지 전시관 · 걷기 버전

### 9월 23일 수정

- **전시관 분위기 4가지를 실제 전시 공간을 참고한 사진 자산으로 새로 만들었습니다.** 색만 바꾸지 않고 벽·바닥·천장·문·액자·첫 화면 사진이 모두 다릅니다. 새 사진은 `rooms/` 폴더에 있습니다.
  - **클래식 박물관**: 아이보리 벽, 금빛 액자, 헤링본 마루(기존 사진 자산)
  - **유럽 궁전 미술관**: 루브르·우피치 회화관처럼 진홍 다마스크 벽, 바로크 금박 액자, 대리석 체스판 바닥, 금박 격자 천장과 천창, 흰색·금색 쌍여닫이 문
  - **현대 미술관**: 차콜 벽과 스포트라이트, 폴리싱 콘크리트 바닥, 트랙 조명 천장, 흰 매트 검은 액자, 빛이 새어 나오는 출구
  - **조선 궁궐관**: 근정전·인정전 같은 정전 내부. 주칠 기둥과 단청, 띠살 창호, 전돌 바닥, 우물반자 천장, 족자 액자, 꽃살문(입구)과 일월오봉도 병풍(복도 끝)
- **전시관 삭제**: 첫 화면 ‘나의 전시관’ 카드의 **삭제** 버튼, 또는 전시관 안 **⚙ 설정 → 이 전시관 삭제**로 지웁니다. 확인 후 해당 전시관과 작품만 삭제되며 다른 전시관은 그대로 남습니다.
- **카메라 크게 보기**를 위쪽 버튼에서 빼고 **◉ 촬영** 메뉴 안으로 옮겼습니다.

### 9월 19일 수정

- 확대 화면 → 삭제 확인창으로 전환할 때 삭제가 취소되던 오류를 수정했습니다. 아래 **작품 삭제** 버튼으로 사진 목록에서 골라 지울 수도 있습니다. 취소하면 작품은 남고, 삭제하면 새로고침 후에도 빈 칸으로 유지됩니다.
- 전시관 오른쪽 위 **맨 뒤 액자**를 누르면 마지막 번호 액자 앞으로 바로 이동합니다. **번호로 이동** 메뉴로 원하는 칸을 고를 수도 있습니다. 모바일에서도 같은 버튼과 메뉴를 사용합니다.
- **촬영 → 카메라 선택 → 노트북·전면 카메라 → 카메라 시작**으로 노트북 내장 웹캠을 사용합니다. 작품을 카메라 앞에 들고 **지금 촬영**을 누르면 됩니다. QR 자동 촬영도 사용할 수 있습니다.
- 모바일에서는 **휴대폰 후면 카메라**를 선택할 수 있습니다. 구체적인 USB 장치는 목록에 표시된 장치 이름으로 선택합니다. 카메라 자동 선택은 특정 방향을 강제하지 않습니다.

전시관은 이미지로 만든 벽·금빛 액자·나무 바닥으로 구성된 원근 공간입니다. 기본 화면에서 복도를 걸으며 작품을 감상합니다. 배경 이미지는 제작 단계에서 내장 ImageGen으로 생성했고, 앱에서는 포함된 정적 이미지 파일만 읽습니다. 사용 중 AI API를 호출하지 않으며 학생 작품에는 필터를 적용하지 않습니다.

- 작품 등록 후 **이미지가 로드된 시점부터 5초간 크게 감상**합니다.
- 이후 약 **1.25초 동안 해당 벽의 액자로 이동**합니다. 그동안 다음 등록은 잠시 대기합니다.
- 키보드 **↑/W**는 앞으로, **↓/S**는 뒤로 걷습니다. **←/A**, **→/D**는 시선을 좌우로 돌립니다.
- 화면을 마우스나 손가락으로 끌어 둘러볼 수 있습니다. 모바일에는 화면 이동 버튼이 있습니다.
- **이전 작품 / 다음 작품**은 작품이 걸린 벽 앞으로 이동합니다. 빈 칸에도 방문할 수 있습니다.
- **천천히 둘러보기**는 등록된 작품을 순서대로 방문합니다. 작품이 없으면 빈 액자를 따라 걷습니다. **산책 멈추기**로 정지합니다.
- **입구로 돌아가기**는 복도 입구로 이동합니다.
- 아래 **◉ 촬영** 버튼을 누르면 메뉴가 열립니다. **카메라로 촬영하기**는 카메라를 켜고 큰 화면을 엽니다. **카메라 크게 보기**는 숨겨 둔 카메라 화면을 다시 엽니다. **카메라 끄기**로 카메라와 자동 촬영을 멈춥니다. 카메라 화면의 **닫기**는 패널만 숨기며 자동 촬영은 계속합니다. 카메라가 켜져 있으면 촬영 버튼에 빨간 점과 ‘카메라 켜짐’이 표시됩니다.
- **작품 모아 보기**에서는 전체 작품을 한 번에 확인합니다. **전시관 걷기**로 돌아올 수 있습니다.
- 작고 빠른 움직임에 민감한 환경에서는 기기의 ‘동작 줄이기’를 켜면 작품 앞 이동을 즉시 전환합니다. 새 작품을 5초 감상하는 시간은 유지합니다.

이 버전에서는 기존 작품과 설정을 그대로 이어서 사용합니다. 사진 자산은 ``에, 원근 공간과 이동 로직은 `walk.js`, 새 디자인은 `museum.css`에 있습니다. 이미지별 최종 제작 프롬프트·크기·액자 좌표는 `prompts-and-metadata.json`을 참고하세요.

## 가장 빠르게 시작하기

1. 압축을 풀고 `memory-museum` 폴더를 엽니다.
2. Node.js가 있는 Windows에서는 `실행하기.cmd`를 실행합니다. 다른 운영체제에서는 이 폴더에서 `node serve.cjs`를 실행합니다.
3. 브라우저에서 `http://127.0.0.1:4173`을 엽니다. 실행 중인 터미널 창은 열어 둡니다.
4. 이름·작품 수·테마를 선택하고 **새 전시관 만들기**를 누릅니다.
5. **카메라 시작**을 누르고 권한을 허용합니다. 장치 목록에서 USB 실물화상기를 선택합니다.

Node.js가 없고 Python이 있다면 이 폴더에서 `python -m http.server 4173 --bind 127.0.0.1`을 실행하고 같은 주소를 열어도 됩니다. 웹앱 자체는 어느 런타임에도 의존하지 않습니다. 이 명령은 파일을 브라우저에 제공하기 위한 로컬 실행 방법일 뿐입니다.

`index.html`을 더블클릭하는 대신 localhost 또는 아래 GitHub Pages 주소를 사용하세요. 카메라에는 보안 컨텍스트와 사용자 권한이 필요합니다. [브라우저 카메라 공식 안내](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)

## GitHub Pages 배포

공개 주소: https://jbhee7777-afk.github.io/memory-museum/ (GitHub Pages 게시 완료 후 사용). 공유되는 것은 웹앱이며 작품 데이터는 각 기기에 따로 저장됩니다.

1. GitHub에서 새 저장소를 만듭니다. 무료 계정이라면 공개 저장소를 사용합니다.
2. `memory-museum` **폴더 안의 파일과 vendor 폴더**를 저장소에 올립니다. `index.html`이 저장소 최상위에 오게 합니다. ZIP 자체를 올리는 방식은 아닙니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment → Source → Deploy from a branch**를 선택합니다.
5. 브랜치는 **main**, 폴더는 **/(root)**를 선택하고 **Save**를 누릅니다.
6. 배포 완료 후 Pages 화면에 표시되는 HTTPS 주소를 엽니다. 이 주소를 다른 선생님에게 공유합니다.

예시 주소 형식은 `https://사용자명.github.io/저장소명/`입니다. 실제 주소는 GitHub가 표시한 값을 사용하세요. 배포 후 파일을 수정해 main 브랜치에 반영하면 다시 게시됩니다. [GitHub 공식 배포 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

GitHub에는 앱 소스만 올라갑니다. 촬영·업로드한 학생 작품과 이름은 저장소나 외부 서버로 전송하지 않습니다. `serve.cjs`, `실행하기.cmd`, 안내 문서는 웹 실행에 필요하지 않으므로 배포에서 제외해도 됩니다. `vendor`와 앱의 HTML·CSS·JS 파일은 모두 필요합니다.

## 수업에서 사용하기

### 수업 전

- 전자칠판에 연결한 **같은 컴퓨터**에서 앱을 엽니다. 화면 복제/확장으로 전시관을 보여 주세요.
- 전시관 이름, 1~40개 작품 수, 네 가지 테마를 고릅니다. 기본은 24개입니다.
- 실물화상기를 USB로 연결합니다. 카메라 이름은 제조사/드라이버가 제공하므로 미리보기를 보고 원하는 장치인지 확인합니다.
- **QR 만들기 → 공통 QR 만들기 → PNG 저장**으로 `CLASS-EXHIBIT` 마커를 준비합니다. 모든 활동지에 같은 마커를 넣습니다.
- QR은 흰 여백을 포함해 가로 3cm 이상으로 인쇄합니다. 그림을 침범하지 않는 종이 가장자리에 배치합니다.
- 색이 있는 매트 위에 흰 종이를 놓으면 자동 문서 보정이 잘 작동합니다. 반사·그림자를 피합니다.

### 작품 올리기

1. 종이의 네 모서리와 주변 배경이 카메라 안에 들어오도록 놓습니다.
2. QR을 보여 주고 1초 동안 손을 뗍니다.
3. 작품을 5초간 크게 감상한 뒤 벽에 걸리는 애니메이션이 끝날 때까지 기다립니다.
4. 작품을 완전히 치워 QR이 **1.2초 이상** 보이지 않게 합니다. 촬영 후 **1.5초 대기**도 함께 적용됩니다.
5. 다음 작품을 올립니다. 공통 QR은 다음 빈 칸으로 들어갑니다.

카운트다운 중 QR이 사라지거나 다른 QR로 바뀌면 촬영을 취소합니다. **자동 촬영 OFF**, **카메라 끄기**로도 촬영을 멈출 수 있습니다. QR이 흐리면 **지금 촬영 · 수동 촬영**을 누르세요. 수동 촬영도 1초 뒤 촬영합니다.

실물화상기를 쓸 수 없으면 **사진으로 작품 추가**에서 사진을 선택합니다. 여러 장도 가능합니다. 다음 빈 칸부터 추가하며, 칸이 다 차면 멈춥니다. 사진마다 종이 네 모서리와 보정 미리보기를 확인한 뒤 **종이만 잘라 전시하기**를 누릅니다. 최대 4096px로 저장합니다. 원본 사진 파일 자체는 변경하지 않습니다.

### 번호 QR

**번호 QR 만들기**를 누르면 전시 칸 수만큼 `EXHIBIT-01`부터 생성됩니다. 해당 번호 칸으로 바로 배치하며, 이미 차 있는 칸은 덮어쓰지 않습니다. 범위를 벗어나는 번호도 등록하지 않습니다. 공통 QR과 번호 QR은 한 활동지에 하나만 사용합니다.

**A4 인쇄**는 공통 QR을 작품 수만큼 반복하거나 번호 QR을 순서대로 배치합니다. 40개 등 많은 수량은 여러 페이지가 됩니다. 브라우저 인쇄 설정에서 용지를 A4로 선택하고 머리글/바닥글을 끄세요.

### 감상과 관리

- 작품을 누르면 확대합니다. 선택 입력한 학생 이름은 확대 화면과 감상 화면에 표시합니다.
- **설정**에서 제목·작품 수·테마·카메라·자동 촬영·효과음·이름 입력·가로 가이드를 변경합니다.
- 기본 이름 입력은 OFF이며 이름 없이 바로 등록됩니다. ON이면 등록 후 건너뛸 수 있습니다.
- 테마는 기존 작품의 색을 바꾸지 않습니다.
- **마지막 작품 삭제**는 가장 최근에 등록한 작품을 삭제합니다. 확대 화면의 **이 작품 삭제**로 개별 삭제도 가능합니다. 빈 자리는 유지됩니다.
- 작품 수를 줄일 때는 가장 뒤에 작품이 있는 칸까지 유지해야 합니다. 예를 들어 24번 칸에 작품이 있으면 총 작품 수가 적어도 24칸 아래로 줄일 수 없습니다.
- **전시관 걷기**는 카메라 패널을 숨기고 복도를 보여 줍니다. 카메라는 계속 작동하므로 전시관 화면에서도 자동 등록됩니다.
- **전체화면**에서는 제목·작품 중심으로 표시합니다. ESC 또는 **전체화면 종료**로 돌아옵니다.
- 큰 화면에서 **한 화면에 모아 보기**로 전체 작품을 모읍니다. 작은 모바일 화면에서는 가독성을 위해 스크롤 배치를 사용합니다.
- **작품 감상**은 번호 순서로 3초마다 전환합니다. 이전·다음·일시정지·종료 및 방향키를 지원합니다.
- **전시관 이미지 저장**은 모든 작품과 빈 칸, 제목, 수량을 정리한 PNG를 저장합니다. 버튼·카메라 화면은 제외되며, 화면 폭과 관계없이 인쇄/기록용 배열로 내보냅니다. 편집 가능한 전시관 백업 형식은 아닙니다.
- **새 전시관 만들기**는 기존 작품을 보존하며 별도 전시관을 만듭니다. 좌측 상단 제목이나 입구·출구 문을 누르면 로비로 나가 다른 전시관을 골라 들어갈 수 있습니다.

## 자동 잘라내기와 QR 가리기의 범위

Canvas로 밝은 영역을 찾고 연결된 종이 영역의 네 꼭짓점을 추정한 뒤 투영 변환으로 원근을 보정합니다. 종이가 화면 가장자리에 닿거나 배경과 구분되지 않거나 신뢰 조건을 만족하지 못하면 네 모서리를 직접 조절하는 크롭 확인 화면을 엽니다. OpenCV나 AI는 사용하지 않습니다.

이 기능은 모든 배경·종이색·기울기를 처리하는 범용 문서 스캐너가 아닙니다. 어두운 배경의 밝은 종이에 적합합니다. 업로드와 수동 촬영은 항상 보정 화면에서 확인합니다. 자동 촬영은 종이를 찾으면 자동 보정하고, 못 찾으면 확인 화면을 엽니다. 모서리는 터치·마우스로 끌거나 방향키(Shift: 크게 이동)로 조절합니다. 보정한 작품의 비율에 따라 액자도 가로·세로로 바뀝니다.

**QR 흰색 가리기**는 기본 OFF입니다. ON일 때 최종 이미지에서 다시 QR을 찾고, 가장자리의 작은 전시용 QR이며 주변 여백이 흰색일 때만 처리합니다. QR이 크거나 중앙에 있거나 주변이 불확실하면 원본을 유지합니다. 원본 우선 수업에서는 끈 상태를 유지하세요.

## 저장과 개인정보

- 작품·설정은 IndexedDB에 저장합니다. 이름은 기본적으로 수집하지 않습니다.
- 동일 기기·동일 브라우저 프로필·동일 사이트 주소에서 다시 열면 이어서 사용할 수 있습니다.
- 다른 교사의 기기/프로필과 데이터가 섞이지 않습니다. **공용 컴퓨터의 같은 브라우저 프로필**을 쓰면 기존 전시관이 보이므로 교사별 브라우저 프로필을 사용하거나 전시관을 구분해 사용하세요.
- 서로 다른 컴퓨터나 모바일에서 열어도 자동 동기화되지 않습니다. 전자칠판에는 촬영 컴퓨터의 화면을 표시하세요.
- localhost와 GitHub Pages는 별도의 저장 공간입니다. 배포 주소를 바꾸면 기존 작품이 자동 이동하지 않습니다.
- 브라우저 사이트 데이터 삭제, 시크릿 모드 종료, 기기 정리 정책, 저장 공간 회수로 데이터가 없어질 수 있습니다. 수업 후 기록용 PNG를 저장하세요.
- 저장에 실패하면 성공으로 표시하지 않고 기존 작품을 유지합니다. 빈 칸을 다시 촬영할 수 있습니다.
- 같은 전시관을 여러 탭에서 동시에 편집해 덮어쓰지 않도록, Web Locks 지원 브라우저에서는 한 탭만 편집할 수 있습니다. 지원하지 않는 브라우저에서는 한 탭으로 사용하세요.
- 외부 분석 도구·원격 폰트·외부 업로드·AI 호출이 없습니다. JPEG 저장 과정에서 재인코딩하지만 작품의 색상 필터는 적용하지 않습니다.

## 실물화상기 현장 테스트 (수업 전 5분)

1. USB를 연결하고 제조사 프로그램/화상회의 앱을 종료합니다.
2. 앱을 HTTPS 또는 localhost로 열어 카메라를 허용합니다.
3. 카메라 목록에서 실물화상기를 선택하고 미리보기가 실제 책상인지 확인합니다.
4. 흰 A4 종이를 놓고 수동 촬영합니다. 가이드와 저장 영역, 가로·세로 방향을 확인합니다.
5. 공통 QR을 넣은 종이를 촬영합니다. 1초 대기 후 사진 보정을 거쳐 한 칸에 들어가는지 확인합니다.
6. 그대로 10초 두어 한 번만 등록되는지 확인합니다.
7. 종이를 2초 이상 치웠다가 다른 작품을 올려 다음 칸 등록을 확인합니다.
8. 2~3장을 등록한 뒤 새로고침하여 이어서 사용을 확인합니다.
9. 전자칠판 전체화면에서 글씨·작품 크기를 확인합니다. 필요하면 모아 보기와 큰 스크롤 보기를 전환합니다.

## QR 테스트

- 공통 QR → 첫 빈 칸으로 등록되어야 합니다.
- `EXHIBIT-03` → 3번 칸으로 등록되어야 합니다.
- 3번 칸이 찬 뒤 동일 번호 → 덮어쓰면 안 됩니다.
- 설정 수보다 큰 번호 → 안내만 나오고 등록하면 안 됩니다.
- 일반 URL QR → 실행하거나 등록하면 안 됩니다.
- 카운트다운 중 QR을 치우기 → 촬영이 취소되어야 합니다.
- QR 없이 수동 촬영/사진 추가 → 다음 빈 칸으로 등록되어야 합니다.

## 문제가 생기면

| 현상 | 확인할 사항 |
|---|---|
| 카메라 허용 안내 | 주소창의 카메라 권한, 운영체제 카메라 개인정보 설정, HTTPS 주소를 확인합니다. |
| 카메라가 없음 | USB 케이블/포트와 다른 카메라 선택을 확인합니다. 브라우저에서 웹캠으로 인식되는 실물화상기만 가능합니다. |
| 카메라를 시작하지 못함 | 화상회의·제조사 뷰어를 닫고 다시 시작합니다. 연결이 끊겼다면 다시 연결 후 시작합니다. |
| QR이 안 읽힘 | QR 크기를 키우고, 초점/조명/반사를 조절하고, 흰 여백을 유지합니다. QR은 하나만 보여 주세요. 수동 촬영도 가능합니다. |
| 두 번째 작품이 안 찍힘 | 첫 작품을 치워 QR이 1.2초 이상 없어야 합니다. 촬영 후 1.5초도 지나야 합니다. 빈 칸 수를 확인하세요. |
| 종이가 잘못 잘림 | 작품 확대 → 종이 크롭 다시 맞추기에서 네 모서리를 조정합니다. |
| 사진이 안 올라감 | 손상되지 않은 JPG/PNG/WebP로 바꾸고 30MB 이하로 줄입니다. HEIC 지원 여부는 브라우저마다 다릅니다. |
| 저장하지 못함 | 기기의 여유 공간, 브라우저 저장 허용, 시크릿 모드 여부를 확인합니다. 현재 작품을 지우기 전에 기록 이미지를 저장합니다. |
| 새로고침 후 작품이 없음 | 같은 기기·브라우저 프로필·사이트 주소인지 확인합니다. 사이트 데이터를 지웠다면 복구할 수 없습니다. |
| 다른 탭 안내 | 전시관이 열린 다른 탭을 닫고 현재 화면을 새로고침합니다. |
| 효과음 없음 | 설정에서 효과음을 켭니다. 기기 음량과 브라우저 자동재생 제한을 확인합니다. 무음이어도 등록은 계속됩니다. |
| 모바일에서 전체화면 불가 | 브라우저 자체의 전체화면 지원에 따라 다릅니다. 일반 보기에서 감상/사진 추가는 가능합니다. |
| 로컬 주소가 열리지 않음 | 터미널의 서버가 실행 중인지, 4173 포트를 다른 프로그램이 사용하는지 확인합니다. |

## 이번 개선

- 사진 추가 옆 **촬영** 버튼은 큰 카메라 화면을 열고 카메라를 켭니다. **지금 촬영**으로 촬영합니다.
- 감상 사진은 화면을 넓게 사용합니다.
- 이미지로 만든 갤러리 천장과 원목 출입문을 추가했습니다. 문을 누르면 전시관 선택 로비로 이동합니다.
- 이전 버전의 단일 전시관은 최초 로딩 때 자동으로 전시관 목록에 보존됩니다.

## 전체 화면 인식 / 네 전시관 테마
QR은 카메라 전체 화면에서 인식합니다. 작은 가이드에 맞출 필요 없이 종이 네 모서리와 QR이 화면 안에 보이도록 놓으세요. 종이 검출이 확실하면 자동 촬영→종이 보정→게시하며 불확실할 때만 모서리를 확인합니다.
기본 박물관(클래식), 우리 반 미술관(파스텔), 심플 갤러리(화이트 큐브), 전통 전시관(한지·목재·창호)으로 벽·천장·액자·미리보기를 구분했습니다.


## 2026년 10월 2일 — 빠른 촬영과 고화질 저장

QR의 위치 패턴을 원본 영상에서 먼저 찾아 필요한 부분만 확대해 읽고 추적합니다. QR 인식 계산과 고해상도 원근 보정은 별도 Worker에서 처리합니다. QR 인식 후 실제 시계 기준 1초 뒤 촬영하고, 다음 촬영의 최소 대기는 1.5초입니다. 중복 촬영을 막기 위해 작품을 치워 QR이 1.2초 이상 사라져야 하는 조건은 유지합니다.

새 사진은 최대 4096픽셀, JPEG 품질 0.97로 저장합니다. 카메라의 실제 해상도보다 확대 저장하지 않으며, 이미 저장된 저해상도 사진은 다시 촬영해야 합니다. 가로·세로 촬영 설정은 유지됩니다.

Edge 자동 검증: 3840×2880 영상의 1픽셀 모듈 QR 12개 위치·반전 조합, ±20도 기울기와 약한 흐림·그림자 QR 6개 모두 인식했습니다. 3999×2999 사진 보존, 원근 보정의 Worker/일반 결과 일치, 처리 중 화면 응답, 약 1.00초의 촬영 대기, QR 제거 후 재준비 조건을 확인했습니다. 측정 시간은 테스트 기기와 합성 영상 기준이며 실제 초점·조명에 따라 달라집니다.
